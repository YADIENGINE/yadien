# Engine

C++20 / raylib 5.5 oyun engine'i. Ad ve sürüm `EngineManifest.json`'dadır. Oyunlar bu repoyu kökünde `Engine/` submodule'ü olarak alır.

- Belgeler: [Docs/README.md](Docs/README.md)
- Yeni proje: proje klasörüne `Engine/` olarak koyun, proje klasöründen `python Engine new`
  ([Docs/ProjectSetup.md](Docs/ProjectSetup.md))
- Engine testleri: `python . test`
